# Weekly Student Risk Prediction Pipeline

## Overview
This project converts static cutoff-based student risk prediction into a weekly time-series prediction pipeline using the OULAD dataset.

The model predicts:
- student failure risk
- weekly risk progression

## Features
- Behavioral clickstream features
- Engagement trend analysis
- Assessment performance features
- Weekly temporal prediction

## Model
- XGBoost Classifier

## Dataset
OULAD (Open University Learning Analytics Dataset)
